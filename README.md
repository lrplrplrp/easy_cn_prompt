# Easy CN Prompt

在 ComfyUI 里用**中文**写生图提示词，节点输出**英文 Danbooru 标签**。

输入「双马尾」，输出 `twintails`。不用背英文标签，也不用在浏览器和 ComfyUI 之间来回切。

## 特性

- **中文补全** —— 打中文或英文，实时弹出标签候选（内置 33 万条丹波标签）
- **词块编辑** —— 选中后成为词块，显示中文、输出英文；可拖动排序、设权重、单击禁用
- **一键收录** —— 词库里没有的词也能用，之后可批量收进你的词库
- **自动分类** —— 内置模型给词块判类型，置信度阈值可调
- **本地翻译** —— 未收录的中文用 Hy-MT2 翻成英文标签（模型可离线运行）
- **多词库** —— 自己建库、排序、导入导出

## 安装

### 1. 放到 custom_nodes

```bash
cd /path/to/ComfyUI/custom_nodes
git clone https://github.com/lrplrplrp/easy_cn_prompt.git
```

重启 ComfyUI，节点列表里会出现 `Easy CN Prompt (中文提示词)`。

> **Windows 用户**：直接在 `ComfyUI\custom_nodes\` 文件夹里打开终端执行上面两行即可
> （`git clone` 也可换成手动下载 ZIP 解压，注意解压后的文件夹名要是 `easy_cn_prompt`）。

> `ComfyUI\models\easy_cn_prompt\` 目录（没有就新建）。

## 快速上手

1. 新建 `Easy CN Prompt (中文提示词)` 节点
2. 输入「双马尾」
3. 候选框弹出，点一下或按 `Enter`
4. 词块出现，节点输出 `twintails`

多个标签之间默认用**逗号加空格**分隔（`1girl, twintails, smile`）。
想紧凑写法，把节点的 `separator` 切回 `","`。

节点的输出是干净的英文提示词，直接连 `CLIPTextEncode` 即可。

## 用法

### 词块操作

| 操作 | 行为 |
| :--- | :--- |
| **单击** | 切换禁用（不输出，但保留在编辑框里） |
| **双击** | 打开操作菜单 |
| **×** | 删除词块（连同它的逗号） |
| **按住拖动** | 调整顺序（位移超过 5px 才算拖动） |
| **悬浮** | 显示英文 / 中文 / 类型 / 来源 / 状态 |

### 快捷键

| 按键 | 作用 |
| :--- | :--- |
| `↑` `↓` | 选择候选 |
| `Enter` / `Tab` | 确认候选 |
| `Esc` | 关闭候选框 / 取消拖动 |
| `,` | 把前面的文字固化成词块 |

### 逗号自动转换

输入中文逗号 `，` 会自动变成英文逗号 `,`，并把前面的内容固化成词块。
可在节点上关掉（`auto_comma`）。

### 粘贴即转换

粘贴 `1girl, 长发, smile` 会自动拆成三个词块，不用按任何按钮。
从别处复制的词块（带标记的）也能完整还原。

### 权重

双击词块 →「设置权重」。面板有滑块（0~5）、数字框和常用值按钮
（0.5 / 0.8 / 0.9 / 1.0 / 1.1 / 1.2 / 1.5），输出为 `(tag:1.2)`。

粘贴时也会自动识别权重语法。

### 词块颜色

两个维度**互相独立**：

| 视觉 | 表示 |
| :--- | :--- |
| **外框** | **未收录 = 橙色虚线**；已收录 = 无框 |
| **填充色** | **类型**（头发橙棕、服装蓝紫、眼睛蓝……） |

给一个未收录的词指定类型后，**填充色立刻变成该类型的颜色，虚线外框仍在** ——
提醒你它还没进词库。

完整的类型含义与配色见 [分类体系.md](分类体系.md)。

### 整理词块

点编辑框上方的「**整理词块**」，按类型顺序重排，同类聚在一起。

默认顺序按 **Anima 官方提示词格式**：

```
质量词 → 形式(Meta) → 画师 → 角色 → 版权/作品
→ 风格 → 头发 → 头饰 → 眼睛 → 耳朵 → 表情 → 姿势
→ 服装 → 配饰 → 身体特征 → 画面效果 → 镜头 → 视角
→ 背景 → 道具 → 其他 → 待确认
```

可在「设置」里拖动调整；「待确认」固定排在最后。

### 批量禁用

点「**批量禁用**」，弹窗按类型列出编辑框里**实际有**的词块：

```
● 头发   2 个               [不处理][禁用][启用]
● 服装   2 个（1 已禁用）     [不处理][禁用][启用]
```

每类选「不处理 / 禁用 / 启用」，点确定批量应用。
**已是目标状态的词块不会变更**（启用某类不会动原本正常的词块）。

适合"这一批服装标签先全部关掉"这类场景。

### 一键收录

把编辑框里所有「未收录」的词（橙色虚线）一次性收进**默认词库**。

> ⚠️ 需要先在「设置」里指定默认词库。没指定时按钮是灰的。

### 自动分类

未收录的词默认归入「**待确认**」。点「**分类待确认**」，用内置模型自动判断类型。

| 置信度 | 处理 |
| :--- | :--- |
| ≥ 阈值 | 直接采纳 |
| < 阈值 | 保留「待确认」，需手动改 |

阈值可在「设置」→「自动分类」里调（0 ~ 0.99，默认 0.80）。
**调低 = 采纳更多但错误更多**；调到 0 表示全部采纳。

实测参考（601 条测试集）：

| 阈值 | 准确率 | 覆盖率 |
| :---: | :---: | :---: |
| 0.9 | 92.7% | 18% |
| **0.8**（默认） | **89.7%** | 40% |
| 0.7 | 85.3% | 55% |
| 0.6 | 81.7% | 66% |

### 翻译未收录

把未收录的中文词块翻成英文标签（本地 Hy-MT2，离线运行）。

**方向按内容自动判定**：

| 输入 | 方向 |
| :--- | :--- |
| 中文 | → 英文 |
| 纯英文 | → 中文（只补显示名，输出仍是英文） |
| 中英混合 | → 取英文部分译成中文 |

**已翻译过的词块**再点翻译，按中文有没有被改过处理：

| 情况 | 行为 |
| :--- | :--- |
| 中文**没改** | **跳过**，英文保持不变 |
| 中文**改了** | 按新中文重新翻译英文 |

> 跳过是为了避免二次翻译破坏英文（直接把英文译文再翻一遍，
> 可能命中词库里的另一个标签，把 `smiling` 变成 `smile`）。
> 想重译英文时，改一下中文再点翻译即可。

**词库匹配规则**：中文→英文用模糊匹配（帮整句找标签）；
英文→中文用**完全匹配**（避免 `hair` 被曲解成 `long_hair`）。
完全匹配会忽略大小写和下划线/空格差异。

## 词库管理

点编辑框上方的「**设置**」：

- **词库**：新建 / 重命名 / 拖动排序 / 启用禁用 / 导入导出 / 设为默认
- **自动分类**：置信度阈值
- **词块类型顺序**：拖动调整「整理词块」的顺序

词库顺序决定补全优先级（越靠上越优先）。内置的 Danbooru 词库也可以禁用。

### 保存词条到指定词库

双击词块 →「**保存到词库**」，会列出你所有的自定义词库供选择。

### 编辑已收录的词会同步回词库

双击菜单里的这些操作会**直接写回词库**：

| 操作 | 效果 |
| :--- | :--- |
| 编辑英文输出 | 重命名（自定义库）；内置词不改 |
| 编辑中文显示 | 更新中文名 |
| **编辑类型** | 更新分类（**内置词也会直接写入词库**）|

写内置词库（`tag.sqlite`）前会**自动备份**到 `data/tag.sqlite.bak.cat<时间戳>`。

> 内置词只同步类型 —— 中文名是官方译文，且改英文会破坏标签主键。

### 导入格式

支持 `.csv` / `.json` / `.txt`：

```csv
en,cn,category
twintails,双马尾,7
```

## 连线输入

节点的 `text_in` 口可以接文本节点，自动拆分并翻译成英文。

## 基础模型

节点内置 5 种模型规则，影响标签的输出格式：

| 模型 | 输出风格 |
| :--- | :--- |
| 通用（Danbooru） | 原生格式，保留下划线（`long_hair`） |
| Anima | 下划线转空格、画师标签加 `@` 前缀 |
| Illustrious / NoobAI | 下划线转空格，附质量词 |
| Pony V6 | 分数标签风格 |
| Flux（自然语言） | 自然语言句子 |

> 该字段名为「基础模型」是沿用了早期版本的命名，改名会破坏旧工作流。

## API

如果要在别处调用（自定义前端、脚本等）：

| 路径 | 说明 |
| :--- | :--- |
| `GET /easy_cn_prompt/status` | 词库状态、条数、类型元数据 |
| `GET /easy_cn_prompt/search?q=&limit=` | 检索（中英同查，按热度排序） |
| `GET /easy_cn_prompt/lookup?en=` / `?cn=` | 精确查（自定义库优先） |
| `POST /easy_cn_prompt/convert` | 把整段提示词拆分成词块 |
| `POST /easy_cn_prompt/translate` | 批量翻译 |
| `POST /easy_cn_prompt/classify` | 批量分类 |
| `GET/POST /easy_cn_prompt/dicts/*` | 词库管理 |

> ⚠️ 路由挂在 **根路径** `/easy_cn_prompt/*`。前端请用**原生 `fetch()`**，
> 不要用 `api.fetchApi()` —— 后者会加 `/api` 前缀导致 404。

## 数据与升级

| 文件 | 说明 |
| :--- | :--- |
| `data/tag.sqlite` | 内置词库（33 万条中英标签 + 分类结果） |
| `data/custom_dict.db` | **你自己的词库**（首次运行自动创建，升级不受影响）|
| `data/models/setfit_cls/` | 自动分类模型 |
| `data/cls_pkgs/` | 分类依赖（`install_classify.sh` 安装）|

**升级**：`git pull` 即可。你的词库在 `custom_dict.db` 里，不会被覆盖。

## 常见问题

### 翻译一开始能用、过一会儿就不行了？

v0.16.1 已修。原因是空闲清理线程和请求处理争抢同一把锁导致死锁，
旧版本需要重启 ComfyUI 才能恢复。升级即可。

### 翻译很慢或没反应？

- 首次翻译要加载模型（约 1.1GB），可能等几十秒，之后走缓存
- 显存不足时会在 45 秒内放弃 GPU、自动改用 CPU（慢但稳）
- 前端 60 秒兜底超时并提示

排查：① 重启 ComfyUI 清掉卡住的进程 → ② 确认模型在
`models/easy_cn_prompt/` → ③ 看节点的「翻译模型」下拉有没有值

### 提示「找不到翻译模型」？

模型没下载或放错位置，见「安装 → 2. 安装可选功能」。

### 「分类待确认」按钮是灰的 / 提示「未找到依赖目录」？

**分类依赖没装**（约 200MB，不随仓库分发）。在插件目录执行：

```bash
python install_classify.py
```

然后**重启 ComfyUI**。启动日志会显示状态：

```
[EasyCNPrompt] 自动分类：不可用 —— 尚未安装分类依赖（首次使用需要…）
```

装好后变成 `自动分类：就绪`。**其余功能不受影响。**

### 补全找不到某些词？

- 元数据类标签（`bad_id`、`highres`、`c:` 等）已自动过滤
- 词库只含 Danbooru 标签，自定义内容请用「保存到词库」

## 已知限制

- 撤销/重做用的是浏览器原生实现，动态改 DOM 后可能不可靠
- 删除词块只能用 × 按钮
- 中文输入法请人工验证手感（自动化测试覆盖不到真实 IME）

## 开发

```bash
# 后端
easy_cn_prompt/lexicon/     # 词库检索与多词库管理
easy_cn_prompt/routes/      # HTTP API
easy_cn_prompt/nodes/       # ComfyUI 节点
easy_cn_prompt/translate/   # 翻译与分类

# 前端（单文件，无构建步骤）
easy_cn_prompt/web/main.js
```

改前端只需刷新页面；改后端要重启 ComfyUI。
