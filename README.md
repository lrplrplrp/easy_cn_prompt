# Easy CN Prompt — ComfyUI 中文提示词节点

用中文写生图提示词，实际输出英文 Danbooru 标签。

当前状态：**v0.18.0**，可实机使用。

---

## 安装

```bash
cd <你的ComfyUI>/custom_nodes
git clone <本仓库地址> easy_cn_prompt
```

然后**重启 ComfyUI** 即可。不需要跑 pip install。

### 装好就有什么

| 功能 | 是否开箱可用 | 说明 |
| :--- | :---: | :--- |
| 节点 + 中文补全 | ✅ | **词库已随插件打包**（33 万条标签） |
| 词块编辑（颜色/类型/权重/拖动） | ✅ | |
| 词库管理（多库/导入导出） | ✅ | 首次运行自动建「默认」库 |
| **分类待确认**（自动分类） | ✅ | 模型与依赖已随插件打包（295MB） |
| **翻译未收录**（中→英） | ⚠️ 需下载模型 | 见下方「翻译模型」 |

> 插件目录约 **320MB**（含词库 26MB + 分类依赖 203MB + 分类模型 92MB）。

### 翻译模型（可选）

「翻译未收录」需要本地 Hy-MT2 模型，**需自行下载**（约 1.1GB，不便打包）：

```bash
cd <你的ComfyUI>/models/easy_cn_prompt
wget https://hf-mirror.com/tencent/Hy-MT2-1.8B-GGUF/resolve/main/Hy-MT2-1.8B-Q4_K_M.gguf
```

重启 ComfyUI 后，节点里的「翻译模型」下拉会自动列出。
该目录下也有一份 `README.md` 记录这些信息。

## 它是什么

一个 ComfyUI 自定义节点 `Easy CN Prompt (中文提示词)`，输入框里：

- 打中文或英文，下方自动弹出标签候选（像代码补全）
- 点候选项 → 生成一个**词块**，显示中文，实际输出英文
- 逗号由词块自带，**界面上不显示**，序列化时自动补上
- 词块上：**单击**禁用（不输出）、**双击**打开操作菜单、**×**删除（连带逗号）
- 鼠标悬浮显示英文 / 中文 / 类型 / 来源 / 状态（来源会显示**具体词库名**，如「补充词库」「nsfw」）
- 词块按标签类型着色（角色=绿、艺术家=红、版权=紫、常规=蓝、元数据=灰）
- 输入英文逗号 `,` 时，前面的词自动固化成词块
- **词库里没有的词也能成块**：橙色虚线框，按原文输出，方便后续补录
- **粘贴即转换**：粘贴 `1girl, 长发, smile` 自动拆成词块，不需要按任何按钮
- **支持连线输入**：`text_in` 口接文本节点，自动拆分并翻译成英文
- **支持权重**：双击菜单设置 `(tag:1.2)`，粘贴时也自动识别权重语法
- **支持拖动排序**：按住词块拖动调整顺序，带半透明幽灵与插入位预览
- **支持中文翻译**：未收录的词块可一键用 Hy-MT2 翻成英文标签
- **自动转换中文逗号**：输入的中文逗号自动变成英文逗号（可开关）

节点的输出是干净的英文提示词，可直接连 `CLIPTextEncode`。

## 安装

### 1. 放置插件

把插件目录放到 ComfyUI 的 `custom_nodes/` 下：

```bash
cd /path/to/ComfyUI/custom_nodes
git clone https://github.com/lrplrplrp/easy_cn_prompt.git
```

或者在开发时用符号链接（改代码不必重启）：

```bash
ln -s /path/to/easy_cn_prompt/easy_cn_prompt \
      /path/to/ComfyUI/custom_nodes/easy_cn_prompt
```

> 注意：链接的目标是**仓库里的 `easy_cn_prompt/` 子目录**（那才是插件本体），
> 不是仓库根目录。

### 2. 准备词库

插件会自动按以下顺序查找 `tag.sqlite`：

1. 环境变量 `EASY_CN_PROMPT_DB` 指定的路径
2. `easy_cn_prompt/data/tag.sqlite`
3. 插件**上一级目录**下的 `ffdkj-Danbooru_Tag-Chinese-English-Translation-Table/tag.sqlite`

本机词库已就位（329,728 条），无需额外操作。

### 3. 重启 ComfyUI

重启后在节点列表里搜 `Easy CN Prompt`（分类 `EasyCNPrompt`）。

## 用法

1. 新建 `Easy CN Prompt (中文提示词)` 节点
2. 在文本框里输入，例如「双马尾」
3. 候选框弹出后，点一下或按 `Enter` 选中
4. 词块出现，节点输出 `twintails`

> 多个标签之间默认用**逗号加空格**分隔（`1girl, twintails, smile`）。
> 想要紧凑写法，把节点的 `separator` 切回 `","`。

**快捷键**：`↑`/`↓` 选择候选，`Enter`/`Tab` 确认，`Esc` 关闭候选框。

### 拖动排序

**按住词块拖动**即可调整顺序：

- 拖动时鼠标跟随一个**半透明幽灵**，原位置淡化
- 目标位置显示**蓝色虚线插入位**
- 松手即生效，输出顺序同步更新
- 拖动中按 `Esc` 取消

与原有操作不冲突（用 5px 位移阈值区分）：

| 操作 | 行为 |
| :--- | :--- |
| **拖动**（位移 > 5px） | 调整顺序 |
| **单击**（不移动） | 切换禁用 |
| **双击** | 弹出操作菜单 |

### 权重

双击词块 →「设置权重」，面板里有滑块、数字框和常用值快捷按钮（0.5~1.5）。

设置后：

- 词块显示 `双马尾 (1.2)`，并带一圈黄色虚点边框
- 实际输出 `(twintails:1.2)` —— A1111 标准语法，生图模型直接识别
- 权重为 `1.0` 时不加任何后缀
- 「清除权重」可移除

**输入侧也认权重语法**，粘贴这些都能自动识别：

```
(twintails:1.2)      → 权重 1.2
(twintails:0.8)      → 权重 0.8
(twintails)          → 权重 1.1（括号堆叠，每层 ×1.1）
((twintails))        → 权重 1.21
twintails:1.2        → 权重 1.2
```

含冒号的 Danbooru 标签（`c:`、`cyberpunk:_edgerunners`）不会被误判。

### 中文逗号自动转英文

节点有个 **`auto_comma`** 开关（默认**开启**）：

| 状态 | 行为 |
| :--- | :--- |
| `开启` | 你**新键入**的中文逗号 `，` 自动变成英文逗号 `,` |
| `关闭` | 保持原样 |

> 只影响**开启之后新输入**的逗号。编辑器里**已经存在**的中文逗号不会被回头改写 ——
> 这样你调整开关时不会静默改动已有内容。

### 粘贴

粘贴**统一按纯文本处理**：从网页 / Word / 富文本编辑器复制的内容，
会自动剥掉字体、颜色、加粗等格式和多余空白，只保留文字，再解析成词块。

> 剪贴板里同时带 `text/html` 时，浏览器默认会按 HTML 插入（混进 `<span>`、`<b>` 等）。
> 插件一律自己接管插入并清洗成纯文本，所以粘贴结果永远是干净的。

### 粘贴即转换

**直接粘贴**一段提示词就行，不需要点按钮、也不需要快捷键：

```
粘贴：1girl, 长发, smile, 赛博狐狸
结果：「单人女性」「长发」「微笑」三个词块 + 一个橙色「赛博狐狸」（未收录）
```

拆分规则：按中英文逗号、分号、换行切开，逐个查词库；查不到的按「未收录」成块。
工具条右侧显示 `N 个词块 · N 个未收录 · N 个禁用`。

> 只粘贴**单个词**时不会触发转换，仍走智能提示框，避免打断正常打字。

### 基础模型（画师 @ 前缀）

节点有个下拉 **`base_model`**：

| 值 | 说明 |
| :--- | :--- |
| `通用（Danbooru）`（默认） | 标签原样输出（保留下划线） |
| `Anima` | 空格分隔、全小写、画师加 `@` |
| `Illustrious / NoobAI` | 下划线风格 + 自动加 `masterpiece, best quality` |
| `Pony V6` | 下划线风格 + 自动加 `score_9, score_8_up, score_7_up, source_anime` |
| `Flux（自然语言）` | 下划线换空格，自然语言友好 |

**Anima 输出规则**：

| 标签类型 | 规则 |
| :--- | :--- |
| 画师 | 加 `@` 前缀，如 `@dairi` |
| **角色** | 保留原样（含大小写和下划线） |
| **质量词** | 保留原样（含下划线） |
| **其他**（常规/版权/元数据） | **全部小写** + **下划线换空格** |

其他模型的规则：

| 模型 | 大小写 | 下划线 | 自动追加 |
| :--- | :--- | :--- | :--- |
| 通用（Danbooru） | 保留 | 保留 | — |
| Anima | 小写（角色除外） | 换空格（角色/质量词除外） | — |
| Illustrious / NoobAI | 小写 | 保留 | `masterpiece, best quality` |
| Pony V6 | 小写 | 保留 | `score_9, score_8_up, score_7_up, source_anime` |
| Flux | 小写 | 换空格 | — |

> 自动追加的质量词排在**最前面**（Pony 官方要求 `score_` 系列排最前）。

例：`long_hair` → `long hair`，`oshi_no_ko` → `oshi no ko`，
`hoshimachi_suisei`（角色）→ `hoshimachi suisei`，
`masterpiece`（质量词）→ `masterpiece`。

已带 `@` 的不会重复加。编辑框里显示的和最终输出保持一致。

### 质量词

`masterpiece` / `high score` / `great score` / `absurdres` / `best quality` 这类
**模型侧质量词**（Danbooru 原生没有）已内置，搜索时置顶显示、按**金色**着色，
双击菜单「编辑类型」也可以手动把词块标记为质量词。

> Anima 官方正面质量词为 `masterpiece, high score, great score, absurdres`，
> 负面提示词请自行在 CLIPTextEncode 前拼接。

### 连线输入

节点有个可选输入口 **`text_in`**，接任意文本来源（如 `Primitive String`、正则替换节点等）。

**执行后**，上游那段文本会自动拆成词块出现在编辑框里，你能直观看到送来了什么。
中文会被自动翻译成英文标签 —— 上游给 `1girl, 双马尾`，最终输出是 `1girl, twintails`。

> ⚠️ 两点注意：
> 1. 本节点的**输出必须接一个下游节点**，否则 ComfyUI 不会执行它，连进来的文本也就不会显示。
> 2. 连线文本走的是**词库解析**（英文精确 → 中文精确 → 中文子串），查不到的原样保留。

配套下拉 **`mode`**：

| 值 | 行为 |
| :--- | :--- |
| `替换`（默认） | 只用连线内容，忽略手动编辑的部分 |
| `追加` | 连线内容拼在手动编辑的内容后面 |

> 也适用于编辑框与连线内容混合的场景，按需切换。

### 双击词块的操作菜单

| 菜单项 | 说明 |
| :--- | :--- |
| 编辑英文输出 | 就地输入框，改实际送进模型的值 |
| 编辑中文显示 | 就地输入框，只改界面上显示的中文 |
| 编辑类型 | 选常规 / 艺术家 / 版权 / 角色 / 元数据，**颜色随之改变** |
| **设置权重** | 弹面板：滑块 + 数字输入框 + 常用值快捷按钮 |
| 禁用（不输出） | 该词不进入输出 |
| 复制英文 | 复制到剪贴板 |
| 保存到自定义词库 | 写入本地自定义库，之后搜索会优先命中（仅未入库的词条显示） |
| **从自定义词库中删除** | **仅已入库的自定义词条显示**（以库中实际内容为准，重开工作流也正确）；只删库里的记录，编辑框里的词块保留 |

> 删除词块请用词块右上角的 **×**（鼠标悬浮时出现）。菜单里不再提供删除词块项。

### 词库里没有的词

输入没收录的词再打逗号，会生成一个**橙色虚线**词块：

- 实际输出 = 你输入的原文（中文就直接输出中文）
- 双击它 → 「编辑英文输出」改成正确的英文
- 或「编辑类型」指定类型、「保存到自定义词库」存起来，下次就能搜到
- 提示框搜不到结果时不会消失，会显示「未收录「xxx」· 回车按原样成块」

## 数据格式

编辑器里存的是带标记的字符串，交给第三方 API 时也能看得懂：

| 显示 | 实际存储 |
| :--- | :--- |
| 双马尾 | `<chunk>twintails\|cn=双马尾</chunk>,` |
| 微笑（已禁用） | `<chunk>smile\|cn=微笑\|disabled</chunk>,` |

节点执行时会把标记解析掉，只输出英文；`disabled` 的词不会出现在输出里。

> ⚠️ **注意**：如果你把 `EasyCNPrompt` 节点的输出接到了别的地方，
> 或者直接用 `/prompt` API 传 `prompt_text`，请用**节点输出**而不是原始 widget 值，
> 因为原始值里含 `<chunk>` 标记。

## 分隔符

节点输出时，多个标签之间**固定**用「逗号 + 空格」分隔：

```
1girl, twintails, smile
```

分隔符不再提供选项（v0.7 起移除该参数）。

## 整理词块

编辑框上方点「**整理词块**」，会按设置里的**类型顺序**重排词块。

**默认顺序按 Anima 官方提示词格式**：

```
质量词 → 形式(Meta) → 画师 → 角色 → 版权/作品
→ 风格 → 头发 → 头饰 → 眼睛 → 耳朵 → 表情 → 姿势
→ 服装 → 配饰 → 身体特征 → 画面效果 → 镜头 → 视角
→ 背景 → 道具 → 其他 → 待确认
```

即 `masterpiece` 开头、人数和角色名跟在前面、质量增强收尾的官方写法。

- 同类型内**保持原有先后**
- **「待确认」永远排在最后**

### 设置类型顺序

点「**设置**」→「词块类型顺序」区块，类型以**彩色小块**呈现，
**直接拖动**调整先后。不满意的可以点「恢复默认顺序」。

> 「待确认」是锁定项（🔒），固定排在最后，不能拖动。

### 置信度阈值

「设置」→「**自动分类**」区块有个滑块（**0 ~ 0.99**，默认 **0.80**）：

点「分类待确认」时，模型置信度 **≥ 阈值**才直接采纳，低于阈值的保留「待确认」。

| 阈值 | 采纳率 | 准确率 |
| :---: | :---: | :---: |
| 0.9 | 少 | 约 93% |
| **0.8**（默认） | 中 | 约 90% |
| 0.7 | 多 | 约 85% |
| 0.6 | 更多 | 约 82% |

**阈值调低 = 采纳更多但错误更多**，按需权衡。
调到 **0** 表示全部采纳（含低置信度的），适合"先自动填满再人工筛错"。

### 词库排序

同样在「设置」→「词库」区块，**整行拖动**即可调整（越靠上优先级越高）。

## 翻译的行为规则

**权重不参与翻译** —— 词块上的 `(1.2)` 只是显示，翻译只处理词本身，权重照常生效。

**已翻译过的词块**（`en` 是英文、`cn` 是中文）再点翻译时，按**中文有没有被改过**决定：

| 情况 | 行为 |
| :--- | :--- |
| 中文**没改** | **跳过** —— 英文保持不变，不会被二次翻译破坏 |
| 中文**改了** | 按**新中文**重新翻译英文 |

> 为什么要跳过：直接把英文译文再翻一遍，可能命中词库里的**另一个**标签，
> 把 `smiling` 变成 `smile`、`long hair` 变成 `long_hair`。
>
> 想重新翻译英文时，**改一下中文**再点翻译即可。

---

## 翻译与词库的匹配规则

翻译时是否复用词库，**按方向区分**：

| 场景 | 匹配方式 | 说明 |
| :--- | :--- | :--- |
| **中文 → 英文** | **模糊匹配** | 中文常是整句/口语，模糊搜索能帮你找到对应标签 |
| **英文 → 中文** | **完全匹配** | 只认完全一样的标签，避免 `hair` 被曲解成 `long_hair` |
| 中文词粘贴成块 | **模糊匹配** | 同「中文→英文」 |
| 搜索框补全 | 模糊匹配 | 补全本来就该列出多个候选 |

**完全匹配会忽略大小写和下划线/空格差异** ——
`Long Hair`、`long_hair`、`long hair` 都视为同一个标签。

## 编辑已收录的词会同步回词库

包括**内置词库**的词：双击改类型会**直接写入内置词库**（写前自动备份到
`data/tag.sqlite.bak.cat<时间戳>`）。

> 内置词**只同步类型**；英文/中文不改动（内置库的中文是官方译文，
> 且改英文会破坏标签主键）。


如果词块来自你的自定义词库，双击菜单里的以下操作会**直接同步到词库**：

| 操作 | 词库里的效果 |
| :--- | :--- |
| **编辑英文输出** | 相当于重命名（旧条目删除、新条目建立） |
| **编辑中文显示** | 更新该条目的中文名 |
| **编辑类型** | 更新该条目的分类 |

注意：

- 同步回到**原来所在的词库**（不是默认词库）
- **内置 Danbooru 词库是只读的**，不会修改
- 未收录的词（虚线外框）不属于任何词库，编辑只影响当前词块
- 同步失败时界面仍会改好，并弹提示告知（不影响当前工作流）

## 词块的颜色含义

两个维度**互相独立**：

| 视觉 | 表示 |
| :--- | :--- |
| **外框** | **未收录 = 橙色虚线**；已收录 = 无框 |
| **填充色** | **类型**（头发橙棕、服装蓝紫、眼睛蓝…） |

所以给一个未收录的词指定了类型后：**填充色立刻变成该类型的颜色，
但虚线外框还在**——提醒你它还没进词库。

### 一键收录

把所有「未收录」的词一次性收进**默认词库**。

> ⚠️ **默认词库需要你先在「词库管理」里指定**（点「设为默认」）。
> 没有指定时，「一键收录」按钮是**灰的**，点不动。

设置入口：编辑框上方「词库管理」→ 对应词库那一行的「设为默认」。
设为默认后按钮显示为「**★ 默认**」，再点一次可取消。

## 自动分类待确认

未收录的词默认归入「**待确认**」类型。点编辑框上方的「**分类待确认**」按钮，
会用本地 SetFit 模型自动判断它们属于哪一类。

| 模型置信度 | 处理 |
| :--- | :--- |
| **≥0.8** | 直接采纳（实测准确率约 90%） |
| 0.6~0.8 | 保留「待确认」，需要你手动改 |
| <0.6 | 保留「待确认」 |

改类型的方式：**双击词块 →「编辑类型」**。

> 模型放在插件内部（`data/models/setfit_cls/`，92MB），
> 首次点按钮会加载模型（约 2~3 秒），之后是毫秒级。
> 依赖装在插件的独立目录（`data/cls_pkgs/`），
> **不影响 ComfyUI 自身环境**。

## 词库管理

点编辑框上方的「**词库管理**」按钮打开管理页面。

| 功能 | 说明 |
| :--- | :--- |
| **新增词库** | 建一个自己的词库（如「我的画师」「常用姿势」） |
| **重命名** | 改词库名字（内置库不可改） |
| **排序** | 用 `↑` `↓` 调整，**越靠上优先级越高** |
| **启用 / 禁用** | 禁用后该词库不参与提示（内置库也能禁用） |
| **导出** | 导出为 JSON 文件（或 CSV） |
| **导入** | 导入 JSON / CSV，自动建成新词库 |

> **词库顺序决定智能提示优先级**：排在前面的词库，同名词会优先出现在候选列表里。
> 比如你在自定义库里存了 `long_hair = 我的长发`，把它排在内置库上面，
> 搜 `long_hair` 时优先显示你的版本。

### 保存词到指定词库

双击词块 →「**保存到词库 ›**」→ 悬停展开词库列表 → 点目标词库即可。

### 导入格式

**JSON**（推荐）：

```json
{
  "name": "我的词库",
  "tags": [
    {"en": "long_hair", "cn": "长发", "category": 7},
    {"en": "smile",     "cn": "微笑", "category": 10}
  ]
}
```

**CSV**：

```csv
en,cn,category
long_hair,长发,7
smile,微笑,10
```

## 翻译（中文 → 英文）

未收录的词块（橙色虚线框）可以翻译成英文 Danbooru 标签。

### 准备模型

1. 下载 Hy-MT2 的 GGUF（推荐 `Hy-MT2-1.8B-Q4_K_M.gguf`，约 1.1GB）：

```bash
cd /path/to/ComfyUI/models/easy_cn_prompt
wget https://hf-mirror.com/tencent/Hy-MT2-1.8B-GGUF/resolve/main/Hy-MT2-1.8B-Q4_K_M.gguf
```

2. **重启 ComfyUI**，节点的「翻译模型」下拉会自动列出它。

> ⚠️ 别用 1.25bit / 2bit 版本 —— 它们依赖尚未合入 llama.cpp 主线的 STQ 内核，本机加载不了。
> 目录里已放了一份 `README.md` 记录这些信息。

### 使用

| 方式 | 操作 |
| :--- | :--- |
| **批量翻译** | 工具条点「**翻译未收录**」，把所有橙色词块一次翻完 |
| **单个翻译** | 双击词块 →「**翻译此词块**」 |

### 翻译方向（自动判定）

规则一句话：**内容永远是英文，显示永远尽量是中文**。

| 你输入的内容 | 实际输出（送模型） | 词块上显示 |
| :--- | :--- | :--- |
| **中文** `赛博狐狸` | 翻成英文 → `Cyber fox` | 赛博狐狸（保留原文） |
| **英文** `cyber fox` | **保持不变** `cyber fox` | 赛博狐（翻成中文） |
| 中文 `双马尾` | **`twintails`**（词库） | 双马尾 |
| 英文 `twintails` | `twintails` | **双马尾**（词库） |

### 词库优先

**词库里有的，直接查表，不跑模型** —— 词库是人工校对的官方中英对照，比模型准也快得多。

只有词库查不到时才动用 Hy-MT2。英文翻出中文后，还会拿这个中文**再查一次**词库
（比如把 `kitty ears` 翻成「猫耳」，词库命中就会用正式标签 `cat_ears`）。

翻译结果会**统一转成小写**（主流绘画模型的标签都是小写，模型常返回首字母大写，
直接进提示词会降低命中率）。

翻译结果有缓存，同一个词第二次翻译是瞬时的。

### 翻译一开始能用、过一会儿就不行了？

v0.16.1 已修复一个**必须重启 ComfyUI 才能恢复**的死锁：

- **原因**：空闲清理线程（每 30 秒检查一次）在持有锁的情况下又去调用了
  "会再次获取同一把锁"的关闭函数 —— 不可重入锁自己等自己，永久挂死
- **触发条件**：闲置约 10 分钟后（或首个请求刚好撞上清理时机），
  之后所有翻译请求都会卡住
- **现在**：已改为无锁内部版本，空闲清理正常执行，翻译可继续使用

如果你用的是旧版本并遇到这个现象，升级后即可解决。

### 翻译很慢或没反应？

- **首次翻译**需要加载模型（1.8B 约 1.1GB），可能要等几十秒，之后就走缓存
- 若显存被生图模型占用导致 GPU 初始化失败，插件会在 **45 秒内放弃 GPU、自动改用 CPU**（慢但稳），并且**本次运行期间**记住这个选择，不再反复尝试
- 前端 **60 秒**兜底超时，超时会有明确提示，不会永远卡在"翻译中…"
- 排查顺序：① 重启 ComfyUI 清掉卡住的进程 → ② 确认模型文件在 `models/easy_cn_prompt/` → ③ 看翻译模型下拉里有没有值

## 编辑框里的快捷键

在编辑框里操作时，ComfyUI 画布的快捷键**不会**被触发：

| 操作 | 行为 |
| :--- | :--- |
| 编辑框内 `Ctrl+C` / `Ctrl+V` | 复制/粘贴**文本**，不会复制或粘贴节点 |
| 画布空白处 `Ctrl+C` / `Ctrl+V` | 正常复制/粘贴**节点**（原功能保留） |
| 编辑框内 `Delete` / `Backspace` | 只作用于文本和词块，不会删除节点 |

## 旧工作流兼容

**旧版本保存的工作流都能直接打开。**

节点参数历经多次增删（新增 `base_model`、`trans_model`，移除 `separator`、
`escape_parens`），而 ComfyUI 的 `widgets_values` 是**按位置**赋值的数组，
旧工作流加载时容易把值灌到错误的控件上。现在加载时会自动校正：

- v0.3 ~ v0.6 的工作流 → 都能正确加载，非法控件值自动退回默认
- 分隔符固定为 `", "`，旧工作流里的紧凑写法会被自动升级

打开旧工作流后若发现节点参数不对，可以删掉节点重新建一个。

## 已知限制（一期）

- **没有可视化管理面板**——自定义词库目前靠双击菜单增删（接口已有，界面留二期）
- **中文输入法**请人工验证手感，自动化测试覆盖不到真实 IME
- 元数据类标签（`bad_id`、`highres`、`c:` 等）**已自动过滤**，不会出现在候选里
- 撤销/重做用的是浏览器原生实现，动态改 DOM 后可能不可靠
- 删除词块只能用 × 按钮（菜单里已按需求移除该项）

### API

| 路径 | 说明 |
| :--- | :--- |
| `GET /easy_cn_prompt/status` | 词库状态、条数、category 元数据 |
| `GET /easy_cn_prompt/search?q=&limit=` | 检索（中英同查，按 post_count 排序） |
| `GET /easy_cn_prompt/lookup?en=` / `?cn=` | 精确查（自定义库优先） |
| `POST /easy_cn_prompt/convert` | 把整段提示词拆分成词块 |
| `POST /easy_cn_prompt/custom/save` | 保存到自定义词库 |
| `GET /easy_cn_prompt/custom/list` | 列出自定义词条 |
| `POST /easy_cn_prompt/custom/delete` | 删除自定义词条 |

> 前端调用请用**原生 `fetch()`**，不要用 `api.fetchApi()`——后者会加 `/api` 前缀导致 404。
